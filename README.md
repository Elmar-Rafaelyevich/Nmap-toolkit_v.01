# 🔍 NMAP Scanner Menu v.01

**Простой и удобный Bash-скрипт для сканирования сетей с помощью Nmap.**  
Скрипт предоставляет интерактивное меню с 10 типами сканирования и цветным выводом.

---

## 🚀 Возможности

- ✅ 10 типов сканирования Nmap:
  - SYN-сканирование (`-sS`)
  - TCP-сканирование (`-sT`)
  - UDP-сканирование (`-sU`)
  - FIN-сканирование (`-sF`)
  - ACK-сканирование (`-sA`)
  - Определение версий служб (`-sV`)
  - Определение ОС (`-O`)
  - Агрессивное сканирование (`-A`)
  - Быстрое сканирование 100 портов (`-F`)
  - Все порты (1-65535) (`-p-`)
- ✅ Выход по команде `0` или `Quit`
- ✅ Проверка ввода (только числа 1–10)
- ✅ Запрос IP-адреса только для корректного выбора
- ✅ Цветной вывод для удобства
- ✅ Защита от пустого ввода

---

## 📦 Требования

- **Bash** (версия 4.0+)
- **Nmap** (установленный)

```bash

```
